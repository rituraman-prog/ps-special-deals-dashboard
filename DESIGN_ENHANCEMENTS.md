## 🎨 Design System

### Color Scheme:

| Element | Color | Usage |
|---------|-------|-------|
| Primary | Coral Red (#e76f51) | Holdback, accents, CTAs |
| Secondary | Warm Orange (#f4a261) | Framework, highlights |
| Tertiary | Golden Amber (#e9c46a) | Umbrella, success |
| Background | Warm Cream (#fff5ee) | Cards, panels |
| Text Dark | Brown (#4a3426) | Headings, emphasis |
| Text Medium | Brown (#7a5a45) | Body text |
| Text Light | Brown (#9d7a5e) | Secondary text |

### Typography Scale:

| Use | Font | Size | Weight |
|-----|------|------|--------|
| Page Title | Outfit | 2.2rem | 700 |
| Section Title | Outfit | 2rem | 700 |
| Card Title | Outfit | 1.5rem | 700 |
| Stats Value | Outfit | 3rem | 800 |
| Body Text | Manrope | 0.95rem | 400-600 |
| Labels | Manrope | 0.875rem | 700 |

### Spacing System:

- Small: 8px, 12px
- Medium: 16px, 20px, 24px
- Large: 32px, 40px, 48px
- Extra Large: 56px, 64px

### Border Radius:

- Small: 12px
- Medium: 16px, 20px
- Large: 24px
- Pill: 30px
